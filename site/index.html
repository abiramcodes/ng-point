setup

  1. install the dev dependency

    npm i -D @abiramcodes/ng-point

  2. add the provider once, in app.config.ts

    import { provideNgPoint } from '@abiramcodes/ng-point';

export const appConfig: ApplicationConfig = {
  providers: [provideRouter(routes), provideNgPoint()],
};

  3. teach your agent (optional) — install the skill

    npx skills add abiramcodes/ng-point

Start your dev server, then Alt+Click any element (macOS: option+click) - that is the whole setup. Production builds never load it. The skill command comes from skills.sh, the open skills registry - the CLI detects your agent (OpenCode, Claude Code, Cursor, and 75+ more) and installs into the folder it reads; only the skill folder skills/ng-point/ is ever copied. No npx? curl the repo's skills/ng-point/SKILL.md into .agents/skills/ng-point/ or .claude/skills/ for Claude Code.

Every copy includes
Which component the element belongs to, the exact file and line where it's built, a clean copy of its HTML, where it sits in the app — and any note you type.
Keyboard
Hold Alt and click any element to grab it — on a Mac, hold option instead. Keep Shift held to grab a few more. Alt+arrows re-aims at the box around it, or the piece inside it. Enter copies. Esc closes without copying.
Safety
Runs only while you're developing — it never ships to your users. Passwords, tokens and API keys are hidden automatically before anything is copied. You can also mark any part of the page off-limits (ngPointIgnore) so it's never grabbed.
Works with
Angular 21 and 22, everywhere in your app — pages that load late, pop-up dialogs, even apps built as separate pieces. One bonus detail (the template's exact line) appears only on Angular 22.1.4 or newer.
